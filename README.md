# videomax

Clean architecture starter generated by the clean-arch scaffold.

## Run

```bash
./scripts/init.sh
```

The script prepares env files, installs dependencies when needed, starts the backend, and validates `/health`.

Stop the app with:

```bash
./scripts/stop.sh
```

Reset local generated state with:

```bash
./scripts/stop.sh --clean
```

## Quality

```bash
./scripts/run-gates.mjs
```

Use the wrapper above for backend gates.

## Database

This project uses PostgreSQL and Prisma.

After editing `apps/backend/prisma/schema.prisma`, create a migration with:

```bash
./scripts/migrate-dev.sh -- --name <change>
```

## Web

When generated with Next.js, `./scripts/init.sh` starts both backend and web.
The web app calls the backend server-side through `BACKEND_INTERNAL_URL`.
